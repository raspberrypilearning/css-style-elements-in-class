有时，你会想要为具有特定类的**容器**内的特定元素设置样式。 要做到这一点，你可以使用 `>` 运算符。

你刚刚使用的示例对具有 `nav-items` 类的容器内的所有 `<a>` 元素进行了样式设置。

这使你可以设置某些链接的样式，而不会影响页面上的所有链接。 它使你不必为每个单独的链接指定一个类别。

## --- code ---

language: css
filename: style.css
line_numbers: true
line_number_start: 55
line_highlights: 56-60
-----------------------------------------------------------

.nav-items > a {

}

\--- /code ---
